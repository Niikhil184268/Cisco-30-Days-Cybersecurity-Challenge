# Cisco 30-Day Cybersecurity Challenge

> Build real cybersecurity skills in 30 days — **Learn → Do → Log**.

This repository is my public learning journal for the Cisco 30-Day Cybersecurity Challenge. I will work through the planner one day at a time, complete the core task, record what I learned, and track my progress.

The challenge is self-paced. The original planner estimates **20–60 minutes per day**. Beginners can complete the core task; the planner also includes optional stretch activities for certification holders.

## My challenge goals

- [ ] Build a consistent 30-day cybersecurity learning habit.
- [ ] Complete the daily learning and hands-on/reflection tasks.
- [ ] Keep evidence, notes, commands, screenshots, and lessons learned.
- [ ] Review my progress and identify areas to improve.
- [ ] Choose a Cisco credential and create a next-step study plan.

## 🔥 30-day challenge tracker

### Week 1 — Security Foundations
*Think like a defender: understand the threats before you stop them.*

- [ ] **Day 01 — Why Cybersecurity Matters**
  - Task: Enroll in and start *Introduction to Cybersecurity*. Complete Module 1 and note three threats that surprised me.
  - Learning notes: [daily-logs/day-01.md](daily-logs/day-01.md)
- [ ] **Day 02 — Threats & Attack Types**
  - Task: Study common threats, malware, and social engineering. Identify one phishing email (do not click links or open attachments) and list its red flags.
  - Learning notes: [daily-logs/day-02.md](daily-logs/day-02.md)
- [ ] **Day 03 — The CIA Triad**
  - Task: Learn Confidentiality, Integrity, and Availability. Write one real-world example of each.
  - Learning notes: [daily-logs/day-03.md](daily-logs/day-03.md)
- [ ] **Day 04 — Passwords & MFA**
  - Task: Audit my own accounts. Enable MFA on three critical accounts and replace one weak password with a unique passphrase.
  - Learning notes: [daily-logs/day-04.md](daily-logs/day-04.md)
- [ ] **Day 05 — Cryptography Basics**
  - Task: Learn hashing vs. encryption. Hash a sample file and verify its integrity. Optional: explore Packet Tracer File and Data Encryption.
  - Learning notes: [daily-logs/day-05.md](daily-logs/day-05.md)
- [ ] **Day 06 — Explore Cisco U.**
  - Task: Create a free Cisco U. account, browse a security tutorial or webinar, and bookmark one learning path.
  - Learning notes: [daily-logs/day-06.md](daily-logs/day-06.md)
- [ ] **Day 07 — Reflect & Plan**
  - Task: Review Week 1 notes. Pick a target Cisco credential: CCST, CCNA, CCNP, Cisco Certified Specialist, or Cisco Certificate in Ethical Hacking.
  - Learning notes: [daily-logs/day-07.md](daily-logs/day-07.md)
  - Stretch: Review the 200-201 CCNACBR exam topics and rate myself 1–5 on each domain.

  - Learning notes: [daily-logs/day-11.md](daily-logs/day-11.md)
- [ ] **Day 12 — Access Control**

## 📝 Daily learning log

For each day, open its file in `daily-logs/` and record:

1. What I studied (concepts and terminology).
2. What I did (lab steps, commands, tools, and task outcome).
3. What I learned (key takeaways in my own words).
4. Challenges/errors and how I solved them.
5. Evidence (screenshots, sanitized logs, diagrams, or links).
6. Questions to revisit and tomorrow's next step.

A reusable blank template is available at [`daily-logs/TEMPLATE.md`](daily-logs/TEMPLATE.md).

## 📅 Weekly reviews

At the end of each week, add a short review to [`WEEKLY-REVIEWS.md`](WEEKLY-REVIEWS.md):
- What did I complete?
- What are my three biggest takeaways?
- Which topic needs more practice?
- What practical work or evidence did I produce?
- What is my plan for next week?

## 🛡️ Safety and responsible practice

- Only scan systems, networks, and devices that I own or have explicit permission to test.
- Use intentionally vulnerable lab machines only in an isolated, controlled lab.
- Never commit passwords, API keys, tokens, private keys, personal data, or unredacted sensitive logs.
- Sanitize IP addresses, usernames, hostnames, and screenshots when needed.
- Do not include real phishing links or open suspicious attachments for this challenge.
